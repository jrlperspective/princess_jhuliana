PRINCESS JHULIANA — 7TH BIRTHDAY INVITATION

FILES
- index.html: complete responsive single-page invitation (HTML, CSS and JavaScript in one file).

CUSTOMIZE BEFORE SHARING
1. Open index.html in a text editor or VS Code.
2. Find [Add birthday date], [Add start time], [Add venue name], and [Complete address] and replace with the event details.
3. Edit the party theme and dress-code text if needed.
4. Replace the six gallery placeholder divs with image tags, e.g.:
   <div class="photo"><img src="images/jhuliana-01.jpg" alt="Princess Jhuliana"></div>
   Put your images in an images folder beside index.html.
5. Replace [Your Page Name] in the footer.
6. In the JavaScript near the bottom, replace 'your-email@example.com' in RSVP_EMAIL with the host's email address. The sample RSVP opens the guest's email app; it does not save responses to a database. For online response collection, connect a form service or backend.
7. Double-click index.html to preview locally. Upload the file and images to your web host to publish.

The Google Fonts link requires internet access; system fallbacks are included.
